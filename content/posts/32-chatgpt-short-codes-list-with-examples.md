### **⚡ Quick Command List**

**/eli5** — Explain like I’m 5 (super simple).

> Example: `/eli5: What is blockchain?`

**/eli10** — Explain like I’m 10 (a bit more detail).

> Example: `/eli10: What is quantum computing?`

**/summarize** — Give a summary of the text.

> Example: `/summarize: Summarize this article in 5 points`

Check more: **[ChatGPT Hidden Code](https://techguruplus.com/chatgpt-secret-code-list/)** Here

**/bullet** — Answer in bullet points.

> Example: `/bullet: 5 tips for job interviews`

**/tl;dr** — One-line summary (too long; didn’t read).

> Example: `/tl;dr: Explain this long report`

**/translate:hi** — Translate to Hindi.

> Example: `/translate:hi: Please deliver by Monday`

**/translate:en** — Translate to English.

> Example: `/translate:en: Mera naam Sahib hai`

**/tone:formal** — Make it sound formal and polite.

> Example: `/tone:formal: Write a follow-up email`

**/tone:casual** — Make it sound friendly and casual.

> Example: `/tone:casual: Same email`

**/rewrite** — Rewrite to make it sound better.

> Example: `/rewrite: Improve this paragraph`

**/shorten** — Make it shorter.

> Example: `/shorten: Keep this under 50 words`

**/expand** — Add more detail.

> Example: `/expand: Explain microservices`

**/proscons** — List pros and cons.

> Example: `/proscons: Remote work`

**/compare** — Compare two things.

> Example: `/compare: React vs Vue`

**/steps** — Step-by-step guide.

> Example: `/steps: How to build a website`

**/plan:7day** — Create a 7-day plan (or `/plan:30day`).

> Example: `/plan:7day: Learn basic Python`

**/brainstorm** — Give creative ideas.

> Example: `/brainstorm: Video ideas for a design page`

**/role:teacher** — Answer as a teacher.

> Example: `/role:teacher: Explain the past perfect tense`

**/role:interviewer** — Act as an interviewer.

> Example: `/role:interviewer: For a frontend developer`

**/resume** — Improve or generate a resume.

> Example: `/resume: Improve this resume [paste text]`

**/coverletter** — Write a cover letter.

> Example: `/coverletter: For a UX Designer role`

**/fix-grammar** — Correct grammar and punctuation.

> Example: `/fix-grammar: i have done the task yesterday`

**/explain** — Explain in detail.

> Example: `/explain: How SSL/TLS works`

**/example** — Give examples.

> Example: `/example: CSS flexbox usage`

**/code:js** — Write code (specify language).

> Example: `/code:js: Fetch API example`

**/debug** — Find and fix code errors.

> Example: `/debug: [paste code]`

**/testcases** — Generate test cases.

> Example: `/testcases: For function that adds numbers`

**/sql** — Write or optimize SQL queries.

> Example: `/sql: Select top 10 users from table`

**/regex** — Create and explain a regex pattern.

> Example: `/regex: Email validation`

**/recipe** — Give a recipe with ingredients + steps.

> Example: `/recipe: Quick veg biryani`
